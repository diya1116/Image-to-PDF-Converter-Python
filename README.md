🖼️ Image to PDF Converter

A modern desktop application built with **Python** and **CustomTkinter** that allows users to convert multiple images into high-quality PDF documents with customizable settings.

✨ Features:
- 📂 Add multiple images
- 🔄 Reorder images before conversion
- ❌ Remove unwanted images
- 📄 Multiple page size options
  - A4
  - US Letter
  - Fit to Image
- 📐 Margin options
  - No Margin
  - Small Margin
  - Big Margin
- 🖼️ Portrait & Landscape orientation
- 📑 Convert into:
  - Single PDF
  - Separate PDFs
- 👀 Live preview before conversion
- 💾 Download generated PDF files

🛠️ Built With:
- Python
- CustomTkinter
- Pillow (PIL)
- OS & Shutil Modules

🎯 How to Use:

1. Launch the application.
2. Add one or multiple images.
3. Arrange the image order if needed.
4. Select Page Orientation:
   -Portrait
   -Landscape
6. Select:
   - Page Size
   - Orientation
   - Margin
7. Choose whether to create:
   - A single PDF
   - Separate PDFs
8. Click **Convert to PDF**.
9. Download the generated PDF.
